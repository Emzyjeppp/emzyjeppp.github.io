# ⚡ Antigravity Dev Superpowers & Skills Directory

Selamat datang di direktori kemampuan (**superpowers**) dan keahlian (**skills**) yang terintegrasi di dalam lingkungan pengembangan AI **Antigravity**. File ini mendokumentasikan kapabilitas tingkat lanjut yang dapat dikerahkan untuk mempercepat pembuatan, audit, pengoptimalan, dan pengamanan kode dalam berbagai ekosistem teknologi.

---

## 🎨 1. Frontend & UI/UX Superpowers
Kemampuan khusus untuk merancang antarmuka premium, interaksi mikro yang dinamis, serta migrasi teknologi frontend modern.

*   **`ui-ux-expert` & `ui-ux-pro-max`**
    *   *Deskripsi:* Spesialisasi dalam perancangan UI/UX web dan mobile. Menerapkan harmoni warna, tipografi modern, tata letak responsif, serta elemen interaktif yang memberikan kesan premium.
*   **`hig` (Human Interface Guidelines)**
    *   *Deskripsi:* Menerapkan tiga prinsip utama HIG—*Hierarchy, Harmony, dan Consistency*—ke dalam desain UI/UX untuk memastikan antarmuka yang intuitif dan kohesif.
*   **`tailwind-expert`**
    *   *Deskripsi:* Panduan mendalam untuk konfigurasi *CSS-first* di Tailwind CSS v4, kustomisasi tema, dan desain responsif berperforma tinggi.
*   **`senior-frontend`**
    *   *Deskripsi:* Pengembangan frontend mutakhir menggunakan React 19, Next.js 15, TypeScript, dan Tailwind CSS v4.
*   **`bootstrap-to-modern`**
    *   *Deskripsi:* Melakukan refaktorisasi dan migrasi aplikasi legacy Bootstrap CSS lama ke teknologi modern menggunakan Tailwind CSS v4 dan Alpine.js.

## ⚙️ 2. Backend & Software Engineering Superpowers
Keahlian dalam perancangan sistem backend yang modular, aman, scalable, dan cepat.

*   **`python-programming-expert`**
    *   *Deskripsi:* Penulisan kode Python 3.12+ tingkat lanjut dengan tipe data yang aman (type safety), pemrograman asinkron (async/await), FastAPI, SQLAlchemy, pemaketan menggunakan Poetry/uv, linting dengan Ruff, dan pengujian dengan pytest.
*   **`rust-programming-expert`**
    *   *Deskripsi:* Rekayasa perangkat lunak berbasis Rust (Edisi 2024 / v1.85+) fokus pada keamanan memori, pemrograman asinkron, Axum, SQLx, pengembangan CLI, dan optimasi kinerja.
*   **`fullstack-expert` & `senior-fullstack`**
    *   *Deskripsi:* Pengembangan aplikasi fullstack lintas bahasa (TypeScript, Python, Go, Rust) dan framework (Next.js, FastAPI, Gin, Axum), desain API, arsitektur microservices, DevOps, dan desain sistem.
*   **`bun-runtime-expert`**
    *   *Deskripsi:* Panduan ahli untuk runtime JavaScript/TypeScript Bun untuk membangun, menguji, dan meluncurkan aplikasi dengan kecepatan tinggi.
*   **`mvc-expert`**
    *   *Deskripsi:* Merefaktor codebase PHP legacy menjadi proyek dengan struktur MVC (Model-View-Controller) yang bersih, modular, dan mudah dikelola.
*   **`scalability-clean-code`**
    *   *Deskripsi:* Pedoman arsitektur perangkat lunak untuk menjaga keterbacaan kode (Clean Code, SOLID, DRY) serta kemampuan skalabilitas aplikasi.
*   **`event-driven-architect`**
    *   *Deskripsi:* Perancangan arsitektur microservices, antrean pesan (message queues), Event Sourcing, dan backend skala tinggi.

## ☁️ 3. Database, Cloud, & SaaS Architectures
Kemampuan untuk membangun platform Software-as-a-Service (SaaS) multi-tenant dengan sistem pembayaran dan basis data terisolasi.

*   **`supabase-migration`**
    *   *Deskripsi:* Manajemen database, pembuatan skema migrasi, serta penerapan migrasi database secara aman pada Supabase.
*   **`cloud-hosting-expert`**
    *   *Deskripsi:* Panduan deploy aplikasi SaaS dengan *multiple entry points* pada platform Edge & Serverless modern seperti Vercel dan Cloudflare.
*   **`saas-multi-tenant`**
    *   *Deskripsi:* Desain arsitektur SaaS multi-tenant yang aman menggunakan Row Level Security (RLS), isolasi tenant, dan basis data PostgreSQL.
*   **`saas-billing`**
    *   *Deskripsi:* Implementasi dan audit sistem penagihan (billing) SaaS, siklus status langganan (*subscription state machines*), webhook aman, dan sinkronisasi database lokal.
*   **`saas-mvp-launcher` & `saas-transformer`**
    *   *Deskripsi:* Panduan terstruktur untuk meluncurkan SaaS MVP dari nol serta mentransformasikan aplikasi biasa menjadi platform SaaS lengkap yang siap rilis.

## 🔒 4. Security, Quality Assurance (QA), & Optimization
Alat pertahanan untuk melindungi aplikasi dari kerentanan keamanan dan hambatan performa.

*   **`supabase-security-expert` & `firebase-security-expert`**
    *   *Deskripsi:* Audit keamanan tingkat tinggi untuk Row Level Security (RLS), RBAC (Role-Based Access Control), aturan keamanan (Security Rules), autentikasi, API keys, pencegahan kebocoran data, dan konfigurasi App Check.
*   **`secure-fuzz-testing`**
    *   *Deskripsi:* Penulisan dan integrasi *coverage-guided fuzz tests* dalam bahasa Python, Rust, dan Go untuk validasi keamanan kode.
*   **`e2e-testing-expert`**
    *   *Deskripsi:* Pengujian ujung-ke-ujung (End-to-End) menggunakan Playwright, pengujian unit/integrasi dengan Vitest, dan otomatisasi alur CI/CD.
*   **`app-analyzer-optimizer`**
    *   *Deskripsi:* Analisis arsitektur aplikasi secara mendalam untuk melakukan audit, mendeteksi bottleneck performa, dan melakukan optimasi kode.

## 💤 7. Ponytail (Minimalist Developer Mode)
Filosofi pengembangan yang menentang kompleksitas berlebih (*over-engineering*). Mengutamakan kode sesedikit mungkin, memanfaatkan fungsi bawaan (*standard library*), dan menghindari ketergantungan (dependencies) yang tidak perlu.

*   **`ponytail`**
    *   *Deskripsi:* Memaksa pencarian solusi paling malas yang terbukti berfungsi secara efisien, menggunakan jalur terpendek, dan menghindari fitur mubazir (*YAGNI*).
*   **`ponytail-review` & `ponytail-audit`**
    *   *Deskripsi:* Peninjauan kode dan audit seluruh repositori khusus untuk mendeteksi *over-engineering*, menyederhanakan abstraksi spekulatif, dan menyarankan penghapusan kode mati.
*   **`ponytail-debt`**
    *   *Deskripsi:* Mengumpulkan semua komentar penundaan proyek bertanda `ponytail:` ke dalam buku kas piutang utang teknis agar tidak terlupakan.
*   **`ponytail-gain`**
    *   *Deskripsi:* Menampilkan skor dampak positif dari pengurangan jumlah baris kode dan peningkatan kecepatan eksekusi sistem.
